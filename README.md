# D_NetScanner

**Dilshuppa Net Scanner** is a simple but powerful Python-based network scanning tool. It's designed for ethical hackers and cybersecurity learners to identify live hosts, open ports, and potential vulnerabilities in a local network.

⚠️ **Disclaimer:** This tool is intended for educational and authorized penetration testing purposes **only**. Do not misuse it.

---

## Features

- Automatic local network detection
- Live host discovery using Nmap
- Full TCP/UDP port scanning
- Open port and service detection
- Vulnerability lookup using `searchsploit`
- SMB enumeration (using `smbclient`, `smbmap`, `enum4linux`)
- OS-specific vulnerability scans
- Network traffic capture using `tcpdump`
